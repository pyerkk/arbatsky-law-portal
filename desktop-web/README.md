# Карта статей «Арбатский» — приложение для Windows

Это неофициальное приложение использует настоящую карту и данные правового портала. Она работает локально: можно перетаскивать статьи и категории, добавлять заметки, переключать подписи, пользоваться готовой и своей подборками. Расположение и заметки сохраняются в приложении на устройстве.

## Установка

1. Откройте репозиторий → **Actions** → **Сборка карты-оверлея Windows**. Выберите последний успешный запуск и скачайте `Arbatsky-Map-Overlay-Windows` в разделе **Artifacts**.
2. Распакуйте архив и запустите установщик `Arbatsky Map Overlay Setup … .exe`. После установки запустите программу через меню «Пуск».
3. **Ctrl + Shift + Space** показывает или скрывает окно. **Ctrl + Shift + F2** включает и выключает режим, в котором нажатия мыши проходят сквозь окно. Эти сочетания можно изменить в настройках.

Окно закрывается в системный трей. Для полного выхода используйте меню значка в трее. При первом запуске Windows может предупредить, что приложение не подписано цифровым сертификатом.

## Карта поверх игры

1. Откройте приложение и перейдите в **«Быстрый экран»** или нажмите **«Карта»** на верхней панели.
2. Выберите шаблон и добавьте нужные статьи из каталога. Нажмите **«На весь экран»** — каталог скроется, а карта займёт окно на текущем мониторе.
3. Перетаскивайте статьи и категории, добавляйте заметки кнопкой **«＋ Текст»** и выбирайте вид подписей. Нажмите статью, чтобы открыть сведения.
4. Вернуться к каталогу можно кнопкой **«Вернуться»** или клавишей **Esc**. Чтобы управление мышью перешло к игре, включите режим **«Сквозь окно»**; вернуть управление можно глобальным сочетанием клавиш или через трей.

В настройках доступны прозрачность, режим поверх других окон и запуск вместе с Windows. Размер и положение обычного окна запоминаются. Положение карты, избранное и заметки хранятся в локальном хранилище приложения, отдельно от браузера и старой WPF-версии; переноса сохранений между ними нет.

## Обновление базы

При отсутствии сети приложение использует встроенную базу или последнюю успешно скачанную копию. Кнопка **«Обновить базу»** получает файлы JSON с сайта проекта, проверяет их структуру и заменяет копию только после успешной загрузки. Ваши подборки и заметки сохраняются. База может устареть — сверяйте важные условия с указанными на сайте источниками.

## Совместимость

Программа представляет собой обычное окно Windows поверх других окон и не внедряется в игру. Оконный или безрамочный режим игры лучше подходит для отображения оверлея; эксклюзивный полноэкранный режим может скрывать его. Отображение поверх игры и совместимость с её защитой должны быть проверены на конкретном компьютере. Обход античита не предусмотрен.

## Разработка

Необходимы Node.js и npm. Из корня репозитория скопируйте `dist` в `desktop-web/web`, затем выполните внутри `desktop-web`:

```powershell
npm install
npm test
npm start
npm run build:win
```

Сборка содержит локальную копию статических файлов сайта. Для Windows GitHub Actions выполняет тест базы, проверку загрузки карты и сборку установщика.
