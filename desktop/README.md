# Правовой портал «Арбатский» · приложение для Windows

Компактный неофициальный игровой справочник поверх окон. Использует ту же базу, что и сайт: УК, УПК, КоАП, ПГО, закон и устав ФСБ, права задержанного и шпаргалки. Вы можете искать статьи, собирать свою таблицу и копировать сведения, не отправляя их в игровой чат.

## Установка и запуск

1. На странице репозитория откройте **Actions → Сборка приложения Windows** и выберите успешный запуск для нужной версии. В разделе **Artifacts** скачайте `ArbatskyOverlay-Windows-x64` (для скачивания GitHub может потребовать вход).
2. Распакуйте архив полностью в отдельную папку. Запустите `ArbatskyOverlay.exe`. Это автономная сборка для Windows x64; устанавливать .NET отдельно не требуется. Подписанного установщика пока нет.
3. Нажмите **Ctrl + Shift + Space**, чтобы показать или скрыть окно. Значок приложения находится в системном трее.
4. В настройках можно включить запуск вместе с Windows, изменить горячие клавиши, прозрачность и режим поверх окон. Потяните верхнюю часть окна для перемещения и правый нижний угол для изменения размера.

**Ctrl + Shift + F2** включает режим просмотра: мышь проходит сквозь окно. То же сочетание или меню значка в трее возвращает управление окном. Закрыть приложение можно через пункт **«Выход»** в трее. Когда окно активно, `Esc` скрывает его.

В настройках задайте свободные сочетания через `+`, например `Ctrl+Shift+F3`. Если комбинация занята, приложение оставит прежнюю. Чтобы горячие клавиши не мешали вводу, они игнорируются, пока курсор находится в текстовом поле приложения.

## Подборки и поиск

Вкладка **«Моя подборка»** сначала содержит популярные статьи. Кнопка `+` добавляет запись, `✓` удаляет её, а стрелки меняют порядок. Звезда отдельно управляет избранным. Найдите запись по номеру, названию или словам из описания; фильтр ограничивает результаты выбранным документом.

## База и офлайн

Встроенная база находится внутри приложения. В настройках кнопка **«Проверить обновление базы»** загружает JSON непосредственно с сайта проекта. Все файлы проверяются и сохраняются вместе; при ошибке сохраняется предыдущая копия. Дата последнего успешного обновления указана в настройках. Личные настройки и подборки хранятся отдельно в `%LOCALAPPDATA%\ArbatskyOverlay`.

При отсутствии сети приложение использует сохранённую копию, а при её отсутствии — базу, встроенную в сборку. Сведения сокращены и могут измениться: проверяйте условия и действующую редакцию на форуме.

## Сборка из исходников

На Windows x64 установите .NET 8 SDK, откройте терминал в корне репозитория и выполните:

```powershell
dotnet publish desktop/ArbatskyOverlay/ArbatskyOverlay.csproj -c Release -r win-x64 --self-contained true -o output
```

Для проверки без публикации:

```powershell
dotnet run --project desktop/ArbatskyOverlay/ArbatskyOverlay.csproj
```

Приложение собирает базу из `dist/*.json` сайта; хранить вторую копию этих файлов в исходниках не требуется.

## Совместимость и ограничения

Окно является обычным окном Windows с режимом поверх других окон: приложение не внедряется в игру и не меняет её файлы. Оконный и безрамочный режимы игры обычно подходят лучше; в эксклюзивном полноэкранном режиме оверлей может не отображаться. Также отображение и горячие клавиши могут зависеть от уровня прав игры и правил её защиты. Совместимость с «Россия Онлайн» и правилами проекта нужно проверить на своём компьютере; обход защиты приложением не предусмотрен.
