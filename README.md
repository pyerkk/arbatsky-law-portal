# Правовой портал | Арбатский

Неофициальный игровой справочник сервера «Арбатский» проекта «Россия Онлайн». Статический сайт на HTML, CSS и JavaScript без сборщика и сторонних библиотек. Относительные пути позволяют разместить его в подпапке GitHub Pages. Сведения не заменяют актуальную редакцию форума.

## Запуск

В папке проекта выполните `python -m http.server 8000 --directory dist` и откройте `http://localhost:8000`. Не открывайте `index.html` двойным щелчком: браузер может заблокировать загрузку JSON.

## Размещение на GitHub Pages

1. Создайте на GitHub репозиторий `arbatsky-law-portal`.
2. Загрузите содержимое папки проекта в корень репозитория, включая скрытую папку `.github` и папку `dist`. Не загружайте `.openai` — это настройка другого хостинга.
3. В репозитории откройте **Settings → Pages → Build and deployment → Source**, выберите **GitHub Actions**.
4. Отправьте изменения в ветку `main` или запустите workflow **Deploy static site to GitHub Pages** вручную в разделе Actions. Дождитесь успешного завершения.
5. Адрес сайта появится в Settings → Pages и в результате workflow. Для обратной связи добавьте ссылку на Issues своего репозитория в футер сайта.

## Обновление базы

Данные хранятся в `dist/data.json`: массив `documents` содержит документы, `articles` — карточки. У каждой записи уникальный стабильный `id` (он используется в избранном), заголовок, ссылка `url`, дата проверки `checked`, статус и тематические поля. У статьи поля `number`, `official`, `punishment`, `conditions`, `keywords`, `document`. Если данных нет, оставьте номер и наказание пустыми и поясните это в условиях. Не присваивайте статус «действующий» без подтверждения; проверяйте тему и ответы с изменениями. Формат JSON можно проверить командой `python -m json.tool dist/data.json`.

После изменения отправьте файлы в ветку `main`: GitHub Actions повторно опубликует сайт. Даты в карточках реестра означают дату проверки наличия темы в каталоге, а не полную юридическую проверку документа.

## Источники и проверка на 28.10.2026

Использован только [раздел государственных организаций сервера Арбатский](https://forum.russia.online/categories/gosudarstvennyye-organizatsii.1466/), в частности [законодательная база правительства](https://forum.russia.online/forums/zakonodatel-naya-baza.1471/), темы [УК РО](https://forum.russia.online/threads/ugolovnyi-kodeks-ro.39487/), [УПК РО](https://forum.russia.online/threads/ugolovno-protsessual-nyi-kodeks-ro.39485/) и [внутреннего устава ФСБ](https://forum.russia.online/threads/vnutrennii-ustav-federal-noi-sluzhby-bezopasnosti-ro.41645/). В УК и УПК проверены первые сообщения и сообщения о новой редакции; выбранные карточки пересказаны кратко и привязаны к теме. Перечень документов составлен по видимому каталогу, а не на основании полной постатейной проверки всех законов.

Нужны дальнейшая сверка всех частей УК, КоАП, закона о ФСБ, устава, прав и порядка задержания, изменений и возможных отмен. Темы без подтверждённой квалификации не содержат выдуманных номеров. Тексты задержания — черновые игровые фразы, а не полная инструкция. Тест опирается на статью 92 УПК и ссылается на форум. Реальные законы РФ не использованы.

## Обновление материалов и обучение

В `dist/extended.json` находятся три массива: `index` — 164 кратких названия статей УК для поиска, `popular` — строки с частью, звёздами и верхней границей наказания, `quiz` — 50 ситуационных вопросов, варианты, правильный ответ, объяснение и ссылка на форум. Перед обновлением проверяйте не только первую публикацию, но и сообщения о новых редакциях и примечания. Строки таблицы показывают максимум санкции, а не обязательное наказание; отдельные случаи и альтернативные штрафы указаны рядом.

Оглавление охватывает УК, а не все статьи всех документов сервера. Для полного текста УК, УПК, КоАП и устава используйте ссылки на форум. Постатейная база остальных документов и дополнительные изменения требуют дальнейшей проверки.
