# Правовой портал | Арбатский

Неофициальный игровой справочник сервера «Арбатский» проекта «Россия Онлайн». Сайт статический: HTML, CSS и JavaScript без тяжёлых библиотек. Разделы доступны через адреса `#documents`, `#popular`, `#uk`, `#detention`, `#study`, `#saved`, `#fsb`, `#upk`, `#koap`, `#labor` и `#quick`. Для второго монитора откройте `#quick` в новой вкладке и используйте кнопку полноэкранного режима.

## Запуск

В корне проекта выполните `python -m http.server 8000 --directory dist` и откройте `http://localhost:8000`. Загружайте страницу через веб-сервер, а не как локальный файл: браузер может ограничить `fetch()` для JSON.

## Публикация

В Settings → Pages выберите GitHub Actions. Workflow `.github/workflows/pages.yml` публикует папку `dist` после отправки изменений в `main`; его также можно запустить вручную через Actions. Все пути относительные, поэтому сайт работает и в подпапке GitHub Pages.

## Обновление базы

- `dist/data.json` — документы, ссылки и даты проверки каталога.
- `dist/extended.json` — оглавление УК, строки популярных нарушений, звёзды, санкции и 50 вопросов.
- `dist/references.json` — краткие сведения о ФСБ, УПК и трудовом кодексе, оглавление УПК и отдельные статьи КоАП.

Сверяйте первую публикацию и последующие изменения на форуме. Сохраняйте номер, часть, условия, санкцию и ссылку на конкретный первоисточник. Не придумывайте номера, санкции и полномочия. Для проверки JSON: `python -m json.tool dist/extended.json`, аналогично для двух других файлов. Поле даты показывает дату проверки, а не гарантирует нынешнюю актуальность. Избранное и выбранная тема быстрого экрана хранятся в localStorage браузера.

## Источники и пределы базы

Используются только материалы [раздела государственных организаций сервера](https://forum.russia.online/categories/gosudarstvennyye-organizatsii.1466/): [законодательная база правительства](https://forum.russia.online/forums/zakonodatel-naya-baza.1471/), [УК](https://forum.russia.online/threads/ugolovnyi-kodeks-ro.39487/), [УПК](https://forum.russia.online/threads/ugolovno-protsessual-nyi-kodeks-ro.39485/), [КоАП](https://forum.russia.online/threads/kodeks-ob-administrativnykh-pravonarusheniyakh-ro.39488/), [трудовой кодекс](https://forum.russia.online/threads/trudovoi-kodeks-ro.39496/), [закон о ФСБ](https://forum.russia.online/threads/federal-nyi-zakon-o-federal-noi-sluzhbe-bezopasnosti.40142/) и [устав ФСБ](https://forum.russia.online/threads/vnutrennii-ustav-federal-noi-sluzhby-bezopasnosti-ro.41645/). Проверка 28.10.2026.

Оглавления УК и УПК содержат краткие названия, а не полный текст статей; по ссылкам доступен первоисточник. Таблица охватывает выбранные популярные нормы, а не все санкции кодексов. Для остальных документов доступны тематические ориентиры и ссылки, постатейное наполнение не завершено. Сроки в таблице — верхние границы санкций; условия, штрафы, исключения и полномочия необходимо сверять в источнике. Текст прав — краткая игровая формулировка: при задержании УПК также требует разъяснения причины и нормы. Законы реальной РФ в игровую базу не подменяются.

## Дополненная база и шпаргалки

`dist/catalog.json` содержит дополнительные составы особенной части УК: номер, часть, юрисдикцию, звёзды и извлечённые пределы санкций. `dist/general.json` хранит краткие пояснения отдельных статей общей части. `dist/references.json` содержит оглавление КоАП и выбранные административные санкции; `dist/cheats.json` — служебные шпаргалки и их источники. Оглавление и таблица не заменяют текст статьи: учитывайте все признаки, дополнительные меры, альтернативные санкции и примечания. Тексты УПК, КоАП, устава и остальных документов не перенесены целиком; отдельные обзоры и подборки не являются исчерпывающими.

## Быстрый экран и источники

«Мой список» создаётся из популярного шаблона при первом открытии. Нажмите «Все статьи» и кнопку + у нужной части; ✓ удаляет её. «Восстановить шаблон» заменяет персональную подборку. Данные сохраняются только в данном браузере (`arb-quicklist-v1`). Р/Ф/В — метки подследственности в УК. Не делайте из них вывод о полномочиях задержания без проверки УПК и ведомственного закона. Для материалов без подтверждённой метки отображается соответствующее предупреждение. Ссылки на конкретные статьи используют переход по текстовому фрагменту: поддержка зависит от браузера.
